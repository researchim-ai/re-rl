# re-rl / web

Статический интерактивный сайт проекта: HTML, CSS и JavaScript без сборщика и серверных зависимостей. Все файлы для размещения находятся в этой директории.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8765 --directory web
```

Откройте http://localhost:8765. Для размещения на статическом хостинге используйте содержимое `web/`; пути относительные, поэтому поддерживаются и поддиректории.

## Что внутри

- Анимированный SVG-граф reasoning, интерактивная карта шести направлений.
- Каталог 1022 типов из реестров: 965 текстовых, 57 визуальных; поиск, совместные фильтры, пагинация и карточки с условиями и ответами.
- Лаборатория из 1560 настоящих примеров: 26 генераторов, все десять уровней, RU/EN, три варианта. Раскрытие шагов, изображения, сравнение уровней 2 и 9, экспорт JSON.
- Все 57 визуальных превью созданы генераторами; условие и ответ соответствуют тому же экземпляру, что и картинка.
- Шесть подборок по навыкам и объяснения, чему учит каждая из 26 задач; фильтры по разделу, направлению и формату.
- Интерактивное представление текущего примера в SFT, Chat и GRPO; FAQ о сложности, проверке и дедупликации.
- Описание Python API для pretrain, SFT, GRPO и VLM, копирование рабочего примера кода.
- Адаптивная верстка, клавиатурная навигация, нативные диалоги, reduced-motion.

Лаборатория просматривает **предгенерированные** примеры; она не запускает Python в браузере. Каталог — снимок существующего `examples/catalog.html`, проверяемый на совпадение с реестрами. Для типов вне лаборатории отображаются примеры из каталога. Для 29 текстовых графовых семейств и 5 визуальных вариантов каталог обновляется вместе с вычисленными шагами решения. В карточках 26 выбранных типов доступны смена уровня, языка и варианта, переход в лабораторию и Python-пример. Прямые ссылки вида `?task=horn_fire` открывают карточку.

## Обновление данных

В окружении с установленными зависимостями проекта:

```bash
MPLCONFIGDIR=/tmp/re-rl-mpl python web/scripts/build_data.py
python -m pytest web/test_web.py -q
node --check web/app.js
```

Скрипт сверяет ID каталога с обоими реестрами, получает направления из модулей классов, генерирует и проверяет через `verify()` 1560 примеров, сохраняет `data.js` и PNG-превью всех визуальных типов. При расхождении каталога с реестром обновите исходный каталог перед повторным запуском.

`data.js` и PNG хранятся в репозитории: для просмотра сайта Python-пакет устанавливать не нужно. Google Fonts используется для типографики, при недоступности сети работают системные шрифты. Других внешних runtime-зависимостей нет.

Проверка сайта не заменяет тестирование корректности всех генераторов библиотеки. Число уровней отражает интерфейс сложности; фактическое изменение параметров зависит от реализации задачи.

Дополнительно генерируются 240 PNG для визуальных примеров лаборатории (4 типа × 60 экземпляров). Пути к изображениям в экспортируемом JSON относительны каталогу `web/`; переносите изображения вместе с записями. Примеры форматов на сайте иллюстрируют поля, а не заменяют Python API.
